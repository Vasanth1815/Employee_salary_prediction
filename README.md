# Employee Salary Prediction 💼

This project uses Machine Learning to predict whether an employee earns more than $50k/year based on census data.

## 🚀 Features
- **Analysis:** Jupyter Notebook exploring the Adult Census Income dataset.
- **Model:** Gradient Boosting Classifier with 85%+ accuracy.
- **Web App:** Interactive Streamlit interface for real-time predictions.

## 🛠️ How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `streamlit run app.py`
